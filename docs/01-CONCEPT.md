# 01. コンセプト

## プロダクト名と一文紹介

- **名称**：yasashii-ja（仮称・リポジトリ名）
- **キャッチコピー**：むずかしい日本語を、伝わる日本語に。文章も、Webサイトも。
- **要約**：日本語を母語としない人に伝わりやすい「やさしい日本語」へ変換し、確認可能なHTMLまたはi18n対応JSONとして利用できるClaude Code向けAgent Skill。

## 解決する課題

「やさしい日本語」が必要だと分かっていても、利用者は次のことを知らないことがある。

1. 何をどう言い換えるべきか（語彙・文法・文章構成）。
2. 期限、金額、申込条件などを変えずに言い換えるには、何を確認すべきか。
3. 変換結果を関係者にどう見せればよいか。
4. Webサイトのi18n言語ファイルをどう用意すればよいか。

変換結果をチャットに貼るだけでは、共有・再利用・Webサイト組み込みの作業が残る。**すぐ確認できるHTML**と**実装に使えるJSON**を生成して、この溝を埋める。

## 誰のためのものか

- **一次ターゲット**：Claude Codeを使い始めたばかりの個人・団体・Web制作者。専門用語を知らなくても「この文章をやさしい日本語にして」と頼める。
- **利用者の典型**：学校のお知らせ担当、自治体の広報担当、地域団体・NPOの担当者、Web開発者。
- **最終的な読み手**：日本語に不慣れな在留外国人や日本語学習者。国籍・出身言語によらず理解しやすさを目指す。ただし個人差があり、すべての人に理解を保証できない。

## コアバリュー

1. **質問のハードルをなくす**：何をどう指定するべきか知らなくても、単純な入力から成果物を生成。
2. **情報を守る**：期限、対象、費用、否定、例外、申込方法等の重要情報の欠落や意味のずれを検査。
3. **すぐ使える成果物**：一枚のHTMLプレビュー、または既存の言語ファイルと同構造のJSON。
4. **人が判断できる**：注意点と原文との差分を示し、確信できない情報は確認事項として残す。
5. **導入が軽い**：専用バックエンド、外部ストレージ、APIキー追加をMVPの必須条件にしない。Claude Codeが利用するモデルで書き換える。

## 他のものとの違い

- 一般の文章リライト：チャット上の文章を返すことが中心。yasashii-jaは**HTMLプレビュー／i18n JSONという再利用可能な成果物**まで作る。
- 先行の `meiseki:yorisoi`：語彙・文法検査とやさしい日本語化を担う。yasashii-jaは**ファイル入力の取り扱い、非破壊出力、JSONの補間変数維持、HTML切り替え表示**をMVP中心に置く。先行OSSの機能やアイデアは尊重し、コードのコピーはライセンス確認後に限定。
- 汎用i18nツール：外国語への翻訳が主な用途。yasashii-jaは**日本語の別表現**を生成する。標準的な言語コードの翻訳ではなく、独自の表示バリエーションとして扱う。

## 成功の定義

- 最初の一回で、非エンジニアでも出力HTMLをブラウザで開き、原文とやさしい日本語を比較できる。
- i18n JSONを与えると、アプリで必要な構造とプレースホルダーを壊さず、別ファイルを得られる。
- 未対応構文や意味の不確実性を黙って無視せず、警告で示せる。
- ガイドラインを参考にした変換の根拠を説明できる。

## 対象外とするもの

- サイト全体のi18n自動導入、データベース翻訳、Webの巡回・スクレイピング
- PDF/DOCX、画像OCR、音声・動画の文字起こし
- 自動公開・デプロイ
- 法的な正しさ・外国語能力試験レベル・実際の理解度の保証

## 開発思想

**「知らないから聞けなかったことを、AIが先回りして補う。」**  
ただし、AIが原文にない事実を補ってしまうのではなく、必要な確認事項を先回りして見つけることを意味する。
