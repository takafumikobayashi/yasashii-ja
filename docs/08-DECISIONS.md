# 08. 技術判断の記録

docs/05「初めに決める必要がある技術項目」への回答。理由と代替案を短く残す。

## D1. 実行環境：Node.js 24 以上・TypeScript をビルドせずに実行（M0、2026-11-23 改訂）

- **決定**：`.ts` を Node.js のネイティブ型除去で直接実行する。`tsc` は型検査だけ（`noEmit`）。テストは `node:test`。ランタイム依存はゼロ、devDependencies は `typescript` と `@types/node` のみ。
- **理由**：スキル利用者にビルド手順を求めずに済む。依存が少ないほどライセンス確認と保守が楽。
- **制約**：型除去で消せる構文だけを使う（`erasableSyntaxOnly`。enum・namespace・パラメータプロパティは不可）。import は `.ts` 拡張子付き。
- **代替案**：tsc で `dist/` にビルド（成果物の管理が増える）、Vitest（依存が増える）。
- **下限を 24 にした理由**（当初は型除去が使える 22.18 を下限にしていた）：
  - v22 は 2027-04-30 にサポート終了。新しいツールの下限には短すぎる。v24 は 2028-04 まで、v26（Active LTS）は 2029-04 まで。
  - v24 から `import.meta.main` が使え、エントリーポイント判定を自前で書かずに済む。
- **版の指定方法**：`engines` には系列だけ（`>=24`）を書き、パッチ番号は書かない（セキュリティリリースのたびに古くなるため）。推奨するパッチ版は README に書く。2026-11-11 のセキュリティリリース時点の推奨は 26.13.1 / 24.22.3 以上。開発用の版は `.node-version`（26）。
- **確認済み**：v24.22.3 と v26.13.1 の両方で、型除去の警告が出ないこととテストがすべて通ることを確認した。

## D2. CLI とスキルの責務境界（M0/M1）

- **決定**：`src/` にコア（分割・検証・HTML生成・保存）を置き、`src/cli.ts` に `prepare` / `render` の2コマンド。スキル（`.claude/skills/yasashii-ja/`）は手順と書き換え方針だけを持ち、CLI を呼ぶ。
- **流れ**：`prepare` → 作業ファイル（work.json、原文の SHA-256 付き）→ Claude が result.json を書く → `render` が照合・HTML生成。
- **理由**：Claude が編集するのは result.json だけにし、原文を構造的に変更できないようにする。原文が改変されれば `render` がハッシュ不一致で拒否する。
- **代替案**：Claude が work.json の `easy` 欄を直接埋める（docs/03 の例に近いが、原文を誤って書き換えても検出が難しい）。

## D3. 文章の受け渡し

- **決定**：直接テキストは Claude が Write ツールで一時ファイルに書き、`--text-file` で渡す。コマンド引数に文章を書かない。
- **理由**：文章中の引用符・`$()` などでシェルのコマンドが壊れたり実行されたりするのを防ぐ。
- 「ファイルの場所らしい」文字列（例：`./docs/notice.md`）が文章として渡されたら、終了コード 2 で止めて確認を求める（`--confirm-text` で続行）。

## D4. 既存ファイルがある場合の既定動作

- **決定**：上書きせず `name-2.html` のように別名で保存し、報告する。`--force` で上書き。入力・作業ファイルは `--force` でも上書きしない。
- **実装**：同じフォルダの一時ファイルに書き切ってから、ハードリンク（既存なら EEXIST）で配置する。ハードリンク非対応の環境では `COPYFILE_EXCL` を使う。途中で失敗しても壊れたファイルは残らない。
- **代替案**：エラーで止めて確認を求める（安全だが初心者には手間）。

## D5. HTML の安全性

- 文字列はすべて5文字エスケープしてサーバー側（CLI）で埋め込む。JS は表示切替だけで、DOM への文字列挿入をしない。
- CSP（`default-src 'none'`）で、ツール自身のスクリプトとスタイルだけをハッシュで許可する。エスケープに漏れがあっても注入スクリプトは実行されない二重の防御。外部への通信も禁止される。
- リンクはページ内アンカーのみ。原文中の URL はテキストとして表示する（docs/03「プレビューのリンクは最初の版で無効化してもよい」）。
- JS が無効でも、原文とやさしい日本語の両方がラベル付きで読める。

## D6. 決定論的な事実照合（品質の第2層の一部）

- `render` 時に、原文の数字（全角→半角、桁区切りを正規化）・URL・メールアドレス・否定表現が変換後にあるかを照合し、無ければ `origin: "auto"` の警告を加える。
- 「見つからない」ことを知らせるだけで、意味の一致を判定しない。警告の状態に「合格」は持たない。
- 漢数字・和暦・曜日は未対応（既知の制限）。
